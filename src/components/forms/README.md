# `components/forms`

Formulários reutilizáveis de domínio (com React Hook Form + Zod):

- Formulários de meta, KPI, comunicado, enquete, infração, reserva, perfil, serviço.
- Cada formulário valida client-side e envia para a API Route correspondente.
- Os schemas Zod ficam em `src/lib/validators` e são compartilhados com o backend.
