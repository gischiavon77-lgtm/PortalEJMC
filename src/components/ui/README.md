# `components/ui`

Componentes base reutilizáveis do design system (átomos e moléculas):

- `Button`, `Input`, `Card`, `Modal`, `Badge`, `Pagination`, `DataTable`, `PageHeader`, `StatCard`, `StatusBadge`, `EmptyState`, etc.
- Sem regra de negócio — apenas apresentação e interação.
- Estilizados com Tailwind e os tokens do design system (tema escuro, `brand` #87000a como única cor de destaque; ver "Identidade visual" no CLAUDE.md).

Veja `.kiro/specs/portal-interno-ejmc/design.md` (seção “Componentes UI Principais”).
