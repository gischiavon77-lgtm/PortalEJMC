# `components/ui`

Componentes base reutilizáveis do design system (átomos e moléculas):

- `Button`, `Input`, `Card`, `Modal`, `Badge`, `Pagination`, `DataTable`, etc.
- Sem regra de negócio — apenas apresentação e interação.
- Estilizados com Tailwind + variáveis CSS do design system (paleta vermelha, glassmorphism).

Veja `.kiro/specs/portal-interno-ejmc/design.md` (seção “Componentes UI Principais”).
