# `components/layout`

Fragmentos de layout do portal autenticado e das páginas públicas:

- `Sidebar` (com itens filtrados por permissão).
- `Topbar`, `MobileMenu`, `AuthBackground` (blobs animados).
- Wrappers de layout que organizam header/sidebar/content.

Consumidos pelos `layout.tsx` de `(portal)` e `(auth)`.
